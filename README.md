# SubVivo for Android

외국어 영상을 **휴대폰 안에서** 받아써서 한국어 자막으로 띄우는 안드로이드 앱입니다. Windows판 SubVivo를 옮긴 것입니다.

- **실시간 자막**: 크롬·유튜브 등 다른 앱에서 나오는 소리를 받아 영상 위에 자막을 띄웁니다. 자막은 손가락으로 끌어 옮길 수 있습니다.
- **파일로 자막 만들기**: 휴대폰에 있는 영상을 재생하지 않고 자막(SRT)을 만듭니다. 언어는 파일마다 자동으로 알아냅니다. 일시정지·계속·취소를 할 수 있고, 화면을 꺼도 계속합니다.
- **목소리별 자막 색**: 목소리를 구분해서 사람마다 자막 색을 다르게 씁니다 (노랑·하늘·연두·분홍·주황·보라, 흰색 = 판단 보류).
- 받아쓰기·목소리 구분은 휴대폰 안에서 합니다(인터넷 불필요). 번역에만 인터넷을 씁니다 (구글 무료 / Claude 유료).

## 설치

1. 휴대폰에서 **https://github.com/RYUArqui/subvivo-android/releases/download/apk/SubVivo.apk** 를 엽니다.
2. 내려받은 `SubVivo.apk`를 누르고, "출처를 알 수 없는 앱 설치"를 묻으면 **허용**합니다.
3. 안드로이드 10 이상, 64비트 휴대폰(대부분의 최신 기종)이 필요합니다.

업데이트도 같은 링크에서 받아 덮어 설치하면 됩니다(설정과 모델 유지).

## 처음 쓸 때

1. **인식 모델**을 고르고 **모델 받기** (처음 한 번, 와이파이 권장)
   - 일본어·중국어·영어·한국어 영상: **SenseVoice** (빠르고 정확)
   - 스페인어·카탈루냐어·포르투갈어 등: **Whisper base** (느리면 tiny, 더 정확하게는 small)
2. **실시간 자막** 탭 → 영상 언어 고르기 → **▶ 실시간 자막 시작**
   - "다른 앱 위에 표시" 허용 → "녹화/전송 시작"(소리 가져가기) 허용
   - 영상 앱으로 가서 재생하면 자막이 뜹니다. 끄려면 알림의 **정지**.
3. **파일로 자막 만들기** 탭 → **영상 추가** → **▶ 시작**
   - 결과: `다운로드/SubVivo/영상이름.ko.srt` (원어 자막도 함께). **저장 위치 바꾸기**로 영상 폴더를 고르면 플레이어가 자막을 바로 찾습니다.

## 알아 둘 점

- 넷플릭스·디즈니+ 등 일부 앱은 다른 앱이 소리를 가져가는 것을 막습니다. 이때는 15초 뒤 안내가 뜨며, **마이크** 방식으로 바꾸면 스피커 소리를 마이크로 받아 자막을 만들 수 있습니다(정확도는 떨어짐).
- 실시간 받아쓰기는 휴대폰 성능에 따라 느릴 수 있습니다. 늦으면 더 가벼운 모델을 고르세요.
- 구글 무료 번역은 공식 서비스가 아니라서 막힐 수 있습니다. 그때는 Claude 번역(API 키 필요)을 쓰세요.

## 만드는 방법 (개발)

GitHub Actions(`.github/workflows/build.yml`)가 빌드합니다. main에 올리면 APK를 만들어 릴리스 `apk`에 올리고, 인식 모델은 처음 한 번 릴리스 `models`에 올려 둡니다.
받아쓰기·VAD·목소리 구분은 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (Apache-2.0)를 씁니다. 모델: OpenAI Whisper, FunAudioLLM SenseVoice, WeSpeaker, Silero VAD.
